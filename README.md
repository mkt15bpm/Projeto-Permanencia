# Relatório Diário — 15º BPM

Aplicação Windows em C# / WPF / .NET 8 para elaboração de Relatórios diários, gestão de VTRs e guarnições, produtividade, ocorrências, auditoria e geração de PDF.

## Dados operacionais

O banco de dados e os backups ficam fora deste repositório, em `C:\Permanencia15BPM`. Eles não devem ser enviados ao GitHub.

## Distribuição

Os instaladores são publicados na área de **Releases** do GitHub, mantendo o código-fonte leve e as versões prontas para download.
